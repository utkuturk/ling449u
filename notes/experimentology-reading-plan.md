# Experimentology excerpt reader

Three readings assembled from the book: 26, 25, and 24 pages (75 total).

The substantive reading text comes from Experimentology. Brief introductions and transitions appear in Noteworthy, a readable handwriting-style font. There are no added worksheets, project prompts, or language-production examples. Original section numbers, wording, punctuation, citations, and figure captions are retained. Boxed digressions are omitted. R code boxes are kept, with the output of running them (one run per chapter, seed 42, so numbers can differ from the book); two `lmer` examples in 7.3 are shown without output because `tea_data` has no `id` column. Margin notes are numbered footnotes, sequential within each reading, at the bottom of PDF pages. The HTML versions use linked notes with return links. Most figures are capped at 1.65 or 2.1 inches tall, with a 2.3-inch limit for detailed tables; the annotated consent form is linked at full size.
